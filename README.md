# Projeto de Análise de Dados – Supermercado Chile 🇨🇱

Neste projeto foram aplicados conceitos fundamentais de Ciência de Dados utilizando Python, Pandas, Matplotlib, Seaborn e Plotly.

## 📊 Objetivos do projeto

* Leitura e tratamento de dados CSV
* Análise estatística descritiva
* Cálculo de média, mediana e desvio padrão
* Identificação de outliers
* Visualização de dados com gráficos
* Criação de mapa interativo

## 🛠️ Tecnologias utilizadas

* Python
* Pandas
* Matplotlib
* Seaborn
* Plotly
* Jupyter Notebook

## 📈 Análises realizadas

* Média e mediana dos preços por categoria
* Desvio padrão dos produtos
* Boxplot da categoria com maior dispersão
* Média de descontos por categoria
* Mapa interativo agrupando categorias e marcas

## 🔍 Principais descobertas

A análise mostrou diferenças significativas entre categorias, presença de outliers e alta dispersão de preços principalmente na categoria de laticínios.

Os gráficos permitiram visualizar padrões importantes de desconto e comportamento dos preços.
